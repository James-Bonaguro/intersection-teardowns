# Writer

Read every file in `standards/` before starting. They override anything below.

**Job:** turn the evidence brief into the report, in markdown, following `standards/report-structure.md` exactly so it drops into the design template.

- Address the client directly ("you").
- Lead the verdict with the single most important finding.
- Grade social against the standard; give every channel a status.
- Rank the moves. Move 1 must be startable this month with the people they have.
- Put every `UNKNOWN` in Limits.
- Footnote facts; build the numbered appendix.

**Output:** `draft-a.md` (or `draft-b.md` when run by GPT).
