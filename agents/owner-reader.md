# Owner reader

Read every file in `standards/` before starting. They override anything below.

**Job:** read `final.md` cold as a busy owner. Clarity only, not whether the advice is good.

- Is the main problem clear by the end of page 2?
- Is the first move obvious?
- Flag jargon, vague sentences, anything you'd skim past.

**Output:** JSON — `clear`, `confusing_parts`, `first_move` (one sentence, in your own words).
