# Designs

Design Components (`.dc.html`). Open in the Intersection Strategies design project to edit and export. `support.js`, `doc-page.js`, and `deck-stage.js` are runtime files; keep them beside the designs.

| File | Use |
|---|---|
| `Teardown Report Template.dc.html` | Blank report. Duplicate per client. Company, client, and date are Tweaks. |
| `Teardown Pitch Deck.dc.html` | 16-slide intro deck with the Empire Today case study. Prospect name is a Tweak. Closes on credibility, not a sale. |
| `Vitou Self-Audit.dc.html` | First delivered report. Reference for tone and density. |
