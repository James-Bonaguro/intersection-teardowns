# Instructions for AI assistants

- This repo is private client work for Intersection Strategies (James Bonaguro).
- Before writing or editing any report content, read every file in `standards/`. They override anything else, including older client files.
- Agent prompts live in `agents/`. Edit the prompt, not the workflow, to change behavior.
- Never present numbers from AI research as verified. Tag everything per `standards/evidence-tags.md`.
- Recommend in spurts: rank the moves, lead with one.
- Designs in `designs/` are Design Components (`.dc.html`). Keep the Analyst Dossier style in `standards/brand.md`. Every report page must fit a letter page.
- Client folders hold client data. Don't copy facts between clients.
