# Instructions for AI assistants

- This repo is private client work for Intersection Strategies (James Bonaguro). Every deliverable says "Prepared by Intersection Strategies" · james@intersectionstrategies.co · 708-420-5462.
- Before writing or editing any report content, read every file in `standards/`. They override anything else, including older client files and this summary.
- Agent prompts live in `agents/`. Edit the prompt, not the workflow, to change behavior.
- Style is Analyst Dossier (`standards/brand.md`): paper #F7F5F0, ink #1A1A1A, oxblood #8B1E2D, Source Serif 4 + IBM Plex Mono. Designs in `designs/` are Design Components (`.dc.html`). Every report page must fit a letter page.
- Human-first: AI may appear in recommendations to clients, never as our method.
- Tag every fact (`standards/evidence-tags.md`): RECHECKED, PUBLISHED, OBSERVED, est., INFERRED, UNKNOWN. Published prices are `observed (published)`, never RECHECKED. Never present numbers from AI research as verified.
- Social standard (`standards/social-standard.md`): LinkedIn leads, the same post cross-posted to Facebook and Instagram, website link in every profile (not every post), a monthly newsletter that a human (and compliance, if regulated) reviews.
- Recommend in spurts: rank the moves, lead with one.
- No pricing or sales CTA in client-facing work. Teardowns are portfolio and door-opener work.
- Every client package = report + cover doc (`templates/cover-doc.md`).
- Client folders hold client data. Don't copy facts between clients.
