# Brand · Analyst Dossier

| Token | Value |
|---|---|
| Paper | `#F7F5F0` |
| Ink | `#1A1A1A` |
| Oxblood (accent) | `#8B1E2D` |
| Oxblood tint (highlight fill) | `#F1E6E3` |
| Secondary text | `#3A3733` |
| Muted / labels | `#6B665D` |
| Rules | `#D9D4C7` |
| Serif (body, headings) | Source Serif 4 |
| Mono (labels, numbers, tags) | IBM Plex Mono |

- Quiet and professional. No gradients, no emoji, no icons for decoration.
- Labels are mono, uppercase, letter-spaced. Numbers are mono.
- Oxblood marks what matters: weak scores, the first move, the "So what" box. Use it sparingly.
- Report pages are US letter and must fit. Deck is 1920×1080; no text under 24px.
