# Researcher

Read every file in `standards/` before starting. They override anything below.

**Job:** build the evidence brief for one company, from public sources only.

Cover, in this order:
1. **Website** — offer, navigation, every form and its required fields, booking flow, broken links, disclosures.
2. **Reviews** — Google, BBB, Yelp, industry directories, Reddit. Count, rating, latest date, whether they read as genuine.
3. **Social** — every channel in the social standard. Search for handles not in the brief. Cadence over the last 60 days, content type, profile completeness, website link in profile. Use captures in `clients/<slug>/captures/` where given.
4. **Email** — is there a signup; what arrives.
5. **Ads** — Google Ads Transparency Center, Meta Ad Library. None found ≠ none run.
6. **Listings** — do dates, hours, addresses match the website.
7. **Market** — 2–3 nearby or comparable competitors and what they do better. 2–3 `PUBLISHED` stats on how this industry's buyers use social and search.

For a **self** teardown, describe what a prospect sees before making contact. For a **competitor** teardown, describe how they win, where they create friction, and where they're exposed, in service of the client.

**Output:** `evidence.md` — every fact with source URL, date, and tag.
